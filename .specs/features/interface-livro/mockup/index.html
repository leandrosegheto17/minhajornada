Mockup da feature interface-livro

As telas novas e a barra de título comum usam o guia do projeto (tokens.css, direção C) e só acrescentam os tokens de tokens-novos.css, listados no fim desta página. Os botões abaixo de cada título abrem a tela inteira no tema escolhido.

Spec: FUN-51 a FUN-92. O texto bíblico é o da Bíblia Livre, igual à fonte.

Novo: modelos de ícone do app, a partir do ícone do MinhaJornada no site LJSSoftware.

3. Modo livro

Tela larga (a partir de 900 px e mais larga que alta): duas páginas lado a lado. Tela estreita: uma página (FUN-73, FUN-74). Cada livro começa no topo de uma página nova, com o nome; o número do capítulo abre o primeiro versículo (FUN-76). Nenhum versículo é cortado (FUN-75). O título abre o seletor de hoje (FUN-84). As setas e o deslize passam a página.

Para o plano: a imagem no app

As fotos aqui são JPG de 1920 px (175 a 360 KB). No app, o pré-cache hoje só guarda png e svg (vite.config.ts:55-58). O plano decide entre ampliar o pré-cache para webp (recomendado: cerca de 150 KB) ou usar PNG, que é bem maior. O crédito da foto também vai para o “Sobre”.
